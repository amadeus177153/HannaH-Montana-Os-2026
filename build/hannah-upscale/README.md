# Dependencias de reescalado

Los scripts históricos utilizan Upscayl 2.15.0, extraído bajo `tools/squashfs-root`, y un entorno Python con Pillow. Instala las herramientas desde sus fuentes oficiales. Los ejecutables, modelos y entornos virtuales no se incluyen en Git.

La reparación final de los iconos se realiza con Pillow y RGBA original en `hannah-repair/scripts/repair.py`.
